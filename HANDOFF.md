### 3. Карточка поверх экрана блокировки — прототип (APK не выпускался)

Замысел Павла: «нажимаешь слово — и только тогда экран разблокируется». Заменить
разблокировку нельзя ни одному приложению; можно рисоваться ПОВЕРХ замка и после ответа

рубит это как Background Activity Launch. Нужно разрешение «поверх других окон», которое
человек выдаёт руками; тумблер теперь ведёт в системные настройки, если его нет.
Не проверена доставка ответа на сервер с этого экрана (данные на эмуляторе подложены из
локального зеркала) — код общий с виджетом.

### Кнопка «Обновить» на плашке действительно обновляет

Павел за день дважды: «нажал обновить — плашка пропала, а версия прежняя». Причин было две:

1. Кнопка делала просто `location.reload()`. Если новый service worker стоял в waiting,

   ждём смены контроллера → сносим только precache-кеши Workbox (картинки слов и кеш API

   установке воркера. Теперь это считается обновлением, только если контроллер уже был.

Кнопка больше не исчезает молча — пишет «Обновляю…» (10 локалей).

**Проверено на бою в браузере:** до нажатия бандл `index-DE3_UVki`, после — `index-CP6rNj1q`

### ✅ Закрыто 11.09.2026 (было: единственная незакрытая задача)

**110 примеров, в которых нет изучаемого слова.** Павел одобрил «отфильтровать и
перегенерить», работа НЕ начата. Признак отбора (детерминированный, даёт кандидатов):

```sql
WITH w AS (SELECT id, lesson_id, word_de, example_sentence,
  regexp_replace(lower(trim(word_de)), '^(der|die|das|ein|eine)\s+', '') AS bare
  FROM words WHERE example_sentence IS NOT NULL AND word_de IS NOT NULL)
SELECT count(*) FROM w JOIN lessons l ON l.id=w.lesson_id
WHERE l.target_lang='de'
  AND position(left(bare, greatest(length(bare)-2, 3)) in lower(example_sentence)) = 0;
```

⚠️ В bash через ssh этот `\s` требует ЧЕТЫРЁХ слешей, иначе артикль не отрезается и
вместо 110 покажет 566 — на этом уже споткнулись.

Треть кандидатов — ложные (отделяемые приставки: `rausgehen` → «gehen raus» корректно).
Значит: отфильтровать моделью малыми пачками → вычитать глазами → перегенерить пример
и перевод → записать. Отдельно известны примеры, где сломан сам немецкий и перевод не
поможет: `siebenundvierzig`/`sieben` («Zusammen: siebenundvierzig», 4+7=47),
`das Mittagessen` (всё расписание дня), `heiß` («Ah, Sie heißt... Nikolov. Dank.»),
`der Quatsch` («Das stimmt nicht, das ist! Quatsch»).
