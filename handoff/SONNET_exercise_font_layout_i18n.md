Павел: «сделай крупный шрифт по умолчанию».

- Файл: `frontend/src/store/settings.js`. Там `VISUAL_DEFAULTS` с `zoom: 1.0`.
- Коммент в файле предупреждает: `1.3` был слишком крупным, не помещалось на простых телефонах.
- **Поставь дефолт `zoom: 1.15`** (золотая середина: заметно крупнее, но влезает на телефон).
- Проверь, что новый пользователь (без сохранённых настроек) получает 1.15, а у кого уже
  сохранён свой zoom — остаётся его выбор (не перетирать сохранённое!).
- Пикер размера в `frontend/src/pages/Settings.jsx` (~строка 404, значения zoom) — убедись,
  что 1.15 присутствует как выбираемый вариант; если шаги пикера, например, 1.0/1.1/1.2 —
  добавь 1.15 или подгони дефолт под ближайший существующий шаг (но не мельче, чем сейчас у Павла ощущается крупным).

## Задача 4 — i18n: 6 новых строк финиш-экрана на все 10 локалей

Я (Opus) добавил новый «веер»-финиш урока в `ExerciseSession.jsx`. Там 6 новых строк пока с
русским фолбэком. Нужно добавить их в объект `exercise` во ВСЕХ i18n-файлах:
`frontend/src/i18n/{ru,en,de,uk,es,fr,bg,tr,ar,sq}.js`.

Ключи и русские оригиналы (переведи по смыслу на каждый язык, стиль — тёплый, обучающий):

```js
nextLesson: 'Следующий урок',                 // строка на кнопке «Следующий урок → Название»
courseProgress: (pos, total) => `Урок ${pos} из ${total}`,  // функция! прогресс по курсу
nextLessonLocked: (date) => `Следующий урок откроется ${date}`,  // функция! дата уже отформатирована
nextLessonSoon: 'Следующий урок откроется по расписанию',
courseDone: 'Это последний урок курса — поздравляю!',
trainWords: 'Тренер по словам урока',         // кнопка перехода к ИИ-тренеру по словам урока
```

Важно:
- `courseProgress` и `nextLessonLocked` — это **функции-стрелки**, как уже принято в проекте
  (пример: `tailsSub: (n) => ...`). Сохрани сигнатуру `(pos, total)` и `(date)` — код их так вызывает.
- Для арабского (`ar.js`) — учти RTL, но текст просто переведи (вёрстку не трогай).
- Проверь, что во всех 10 файлах ключи внутри секции `exercise: { ... }` и синтаксис не сломан
  (запятые). После правок собери фронт: `cd frontend && npm run build` — должно пройти без ошибок.
