# Handoff Флабе: рефакторинг локализации (i18n) — убрать хардкод-строки

Контекст: German/Spanish/English-learning PWA (Fastify + React/Vite). Интерфейс на **10 языках**.
Проблема (слова Павла): «много где локали не работает» — в коде осталось много **захардкоженных
русских строк** в JSX, которые не идут через i18n, поэтому у не-русских пользователей показывается
русский. Задача — вычистить это системно.

## 💸 ГЛАВНОЕ про деньги (правило −70$)
- **Строки интерфейса переводишь САМА, прямо в файлы** — это бесплатно (токены Anthropic).
- **НИКОГДА не дёргай OpenAI** для перевода интерфейса. Если кажется, что нужен OpenAI — СТОП, спроси Павла.
- Контент (слова/упражнения) НЕ трогай — только строки интерфейса.

## Как устроен i18n
- Файлы локалей: `frontend/src/i18n/{ru,en,de,uk,es,fr,bg,tr,ar,sq}.js` — по одному объекту на язык.
- Секции: `nav`, `dashboard`, `exercise`, `vocabulary`, `settings` и т.д. Ключи одинаковые во всех 10.
- Использование в компонентах: `const { t, lang } = useI18nStore()` → `t.exercise.someKey`.
- **Функции-значения** для строк с параметрами (уже принято): напр.
  `courseProgress: (pos, total) => \`Урок ${pos} из ${total}\``, `tailsSub: (n) => ...`.
  Сохраняй сигнатуру во всех 10 локалях.
- Русский (`ru.js`) — эталон/исходник. `de` в приложении часто показывает перевод по-русски
  (LANG_FALLBACK.de = 'ru') — но ключ всё равно заводи во всех файлах.
- Арабский (`ar.js`) — RTL, просто переводи текст (вёрстку не трогай).

## Метод (по шагам)
1. **Найди хардкод.** Ищи кириллицу в строковых литералах JSX (исключая i18n-файлы и комментарии):
   ```
   grep -rnP "[«'\"\`][^«'\"\`]*[А-Яа-яЁё]" frontend/src/pages frontend/src/components \
     | grep -v "i18n/" | grep -vE "^\s*//|/\*|\*/"
   ```
   Отсорти по файлам, собери список видимых пользователю строк (заголовки, кнопки, подписи,
   плейсхолдеры, подсказки). Технические строки (console.log, ключи, комментарии) — пропускай.
2. **Заведи ключи.** Для каждой строки — осмысленный ключ в подходящей секции. Добавь во **все 10**
   локалей с переводом по смыслу (тёплый обучающий стиль). Параметры → функции-стрелки.
3. **Замени в коде** литерал на `t.секция.ключ` (или вызов функции). Проверь, что `t` в области видимости.
4. **Собери**: `cd frontend && npm run build` — зелёная сборка (ошибка = сломан синтаксис локали, запятая).
5. Коммить по областям (понятные сообщения на русском), деплой фронта.

## Известные очаги (начни с них)
- **`frontend/src/pages/Vocabulary.jsx`** — я (Opus) недавно добавил вкладки «Цифры»/«Алфавит»
  target-aware, но **интро-тексты и правила — русский хардкод**: «Числа от 0 до 100 и крупные…»,
  «Алфавит», «Крупные числа», заголовки правил произношения (`DE_RULES`/`ES_RULES` — вторые
  элементы), заголовки секций, `wordRu` в `ES_ALPHABET`/`DE_ALPHABET` (перевод слова-примера —
  показывается всем; для не-русских нужен перевод на их язык, но это уже перевод КОНТЕНТА примеров —
  тут только про русские, если не-русский видит русское; согласуй с Павлом объём). Приоритет —
  интро/кнопки/заголовки, не сами примеры.
- **`frontend/src/pages/Dashboard.jsx`** — проверь подписи/баннеры (напр. «Повторить пройденное»,
  тексты тумблера уже частично в i18n через `t.dashboard.*`, но есть фолбэки-хардкод `|| '...'`).
- **`frontend/src/pages/ExerciseSession.jsx`** — финиш/веер уже с ключами (`t.exercise.*`), но много
  фолбэков `|| 'русский'`. Убедись, что ключи есть во всех 10 (fanNext/fanOtherType/fanProgress/
  nextLesson/courseProgress/nextLessonLocked/nextLessonSoon/courseDone/trainWords/multiVariantHint
  уже добавлены — проверь). Фолбэки можно оставить как страховку, но ключи должны переводить.
- **Компоненты упражнений** `frontend/src/components/*.jsx` — подписи, кнопки, подсказки.
- **`frontend/src/components/Layout.jsx`** — меню/профиль/тосты.
