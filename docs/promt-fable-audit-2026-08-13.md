## Что было найдено и сделано

но виновато было СЛОВО: в словаре стояла спрягаемая форма `hoffst` вместо
инфинитива `hoffen`, и модель честно строила фразу вокруг неё. Перегенерация
упражнения при кривом слове даёт такую же кривую фразу.

## Что проверить — по убыванию важности

**1. Немецкий язык, а не только код.** Это главное. Прогони

```sql
SELECT w.word_de, w.translation_ru, e.payload->>'sentence', e.payload->>'blank'
FROM exercises e JOIN words w ON w.id = e.word_id
WHERE e.type = 'fill_blank' AND e.id IN (SELECT id FROM ...);
```

по урокам 33, 297, 298, 338, 570, 571, 619, 620, 623, 626, 628, 629 (там шли правки)
и **прочитай фразы как носитель**. Ищи: неверное спряжение, неверный падеж после
предлога, неверный артикль, порядок слов, отделяемые приставки (`Ich fange die
Arbeit an` — приставка на месте?). Всё, что звучит не по-немецки, — находка.

**2. Границы `fixAgreement`** (`fillBlankFix.js`, строки ~105–140). Логика:
чинить только позицию сразу за подлежащим, спрягать `ich/wir/ihr`, для `du/er/es`
возвращать `null` (упражнение отбрасывается). Проверь на дырах:
- модальный + инфинитив («Ich kann ___ singen») — не должно трогаться;
- отделяемые глаголы (`anfangen`): `Ich ___ die Arbeit an` — ответ `fange`, верно ли?
- возвратные (`sich ärgern`) — местоимение в предложении обязано быть;
- личные формы на `-n` (`kann`, `bin`) — первая версия превращала их в `kane` и `bie`,
  сейчас есть тест, но проверь, нет ли ещё таких форм (`tun`, `sein`, диалектные).
Тесты: `backend/src/services/fillBlankAgreement.test.js`.

**3. Таблица инфинитивов** в `fix-dictionary.mjs` (константа `VERBS`, ~35 строк).
Составлена вручную. Спорное место: `fängst → anfangen` (выбрано по переводу
«начинаешь»; могло быть `fangen` — «ловишь»). Проверь каждую пару и переводы:
`liegst = лежи` было исправлено на `liegen = лежать`, `löst = решает` → `lösen`.

**4. Не пострадал ли английский курс.** `SELECT count(*) FROM words w JOIN lessons l
ON l.id=w.lesson_id WHERE l.target_lang='en' AND w.word_de IN ('artist','breakfast',
'forest','guest','past','scientist')` — должно остаться 13 записей нетронутыми.

**5. Служебные слова.** 34 помечено, 272 упражнения снято. Проверь, что уроки не
опустели и что `processor.js` (строка ~611) действительно пропускает их при
перегенерации, иначе мусор вернётся.

**6. Проверка системы** — запусти `runSystemCheck()` и оцени правила критически:
нет ли ЛОЖНЫХ срабатываний (одно уже ловили: правило «пример не содержит слова»
обвиняло верные примеры, потому что сравнивало словарную запись целиком).
Ложное правило хуже отсутствующего: его перестают читать.

## Чего делать НЕ надо

- **Не трогать баланс OpenAI без Павла.** Инцидент −70$ был реальным. Любая
  операция, тратящая платный ключ, — сначала смета и явный вопрос. Твои
  собственные токены (Anthropic) — бесплатны, читай и проверяй ими сколько нужно.
- **Не чинить по списку претензий дешёвой модели.** Второй эшелон подтвердил 539
  находок из 794, но ручная вычитка 16 штук дала ~40% реальных: `Das Glas ist voll`
  и `Du fängst das Spiel an` — нормальные фразы, забракованные зря.
- **Не править данные скриптом без режима плана.** Двухшаговость (план → `--apply`)
  сегодня спасла от замены `kann` → `kane` в 20 упражнениях.

## Как работать с продом

```bash
ssh seoshkin-tools-core
cd /home/seosite/translate
docker compose -f docker-compose.prod.yml exec -T backend node -e "..."
docker exec $(docker ps -qf name=translate-db) psql -U german_app -d german_learning -c "..."
```

Скрипты внутрь контейнера попадают только пересборкой образа или `docker cp`.
Отчёты из `/tmp` контейнера забирай сразу: пересборка образа их стирает (сегодня
так потерялись два отчёта аудита на $0.12).

После правок бэкенда: `build backend && up -d backend`, затем **обязательно**
`docker exec ecosystem_router nginx -s reload` — шлюз кеширует IP контейнеров.
