## Быстрая шпаргалка

| Задача | Команда |
|---|---|
| Проверить качество материала | `node scripts/audit-exercises.mjs` |
| Нарисовать недостающие картинки | `caffeinate -i node scripts/draw-images-worker.mjs --mode missing --lang de --limit 999` |
| Перерисовать конкретные | `node scripts/draw-images-worker.mjs --ids 4536,4867` |
| Свести дубли слов | `node scripts/merge-duplicate-words.mjs` (план) → `--apply` |
| Починить маски «Добавь букву» | `node scripts/fix-letter-fill-masks.mjs` → `--apply` |
| Скопировать прод на ноут | `bash scripts/sync-from-prod.sh` |
| Посмотреть, что делала система | Админ → 📜 Журнал |
| Переключить платно/бесплатно | Админ → 🤖 ИИ-провайдер |

Все скрипты сначала показывают план и ничего не меняют. Меняют только с `--apply`.

## 1. Аудит материала — запускать после каждой загрузки уроков

```bash
node scripts/audit-exercises.mjs            # всё
node scripts/audit-exercises.mjs --lang de  # один язык
```

Ничего не меняет и не тратит: читает прод и печатает отчёт. Делит находки на два уровня:

- **🔴 блокер** — упражнение нельзя пройти в принципе;
- **🟡 важно** — пройти можно, но учит неверно.

Что проверяет: невыполнимые маски «Добавь букву»; пропуск в «Заполни пропуск» и наличие
верного ответа среди вариантов; повторы вариантов; битый индекс правильного ответа;
неполные спряжения; пустые слова в диктанте; **язык контента против языка курса**;
род существительного по суффиксу; заглавную букву.

### Урок, который стоил дороже всего

Первая версия аудита нашла «155 проблем» — и половина оказалась ложной. Правила
`-ier→der`, `-chen→das`, `-ion→die` обвиняли **правильные** слова: `das Papier`,
`der Kuchen` (пирог, не уменьшительное), `der Skorpion`. Проверка заглавной ругалась
на `der beste Freund`, где строчное слово — прилагательное.

**Правило с исключениями хуже, чем его отсутствие:** оно заставляет «чинить» исправное.
В аудите остались только суффиксы без исключений. Если добавляете правило — сначала
прогоните на всей базе и посмотрите, что оно ловит.

## 2. Картинки — рисуются на ноутбуке, бесплатно

```bash
caffeinate -i node scripts/draw-images-worker.mjs --mode missing --lang de --limit 999
```

Режимы: `missing` (нет картинки), `photos` (заменить фото на рисунок),
`align` (раздать готовую картинку дублям, без рисования), `--ids 1,2,3` (точечно).

**Почему ноут ходит на сервер, а не наоборот.** Сервер физически не видит ноутбук.
Чтобы видел, ноут пришлось бы выставить в интернет через туннель — тогда домашний
интернет становится частью продакшена, а закрытая крышка ломает генерацию на сайте.
Здесь наоборот: ноут сам забирает работу. Наружу ничего не открыто; ноут уснул —
следующий запуск продолжит с того же места.

Практика: ~2 минуты на картинку (M4), `caffeinate -i` держит машину бодрой, пока идёт
работа. **С закрытой крышкой Mac всё равно уснёт** — оставляйте экран открытым.
Draw Things должен быть запущен.

Цена вопроса: 106 картинок за ночь стоили **$0.00**. Через `gpt-image-1` вышло бы ≈$4.30,
а на всю базу — больше сотни долларов. Ради этого всё и делалось.

## 3. Журнал операций — Админ → 📜 Журнал

Утренняя проверка ночного прогона. Смотреть три цифры:

| показатель | норма |
|---|---|
| **Потрачено** | **$0.000** в бесплатном режиме. Ненулевое = что-то ушло на платный ключ |
| **Ошибок** | 0. Растёт ночью — Draw Things закрылся или ноут уснул |
| **Среднее время** | ~2 мин на картинку. Стало 5 — машина перегружена |

Пишутся: разбор фото (самый дорогой шаг), генерация упражнений, переводы на локали,
расшифровка аудио, каждая картинка. У каждой строки видно **чем считали** —
`local` (бесплатно) или `openai` (деньги) — и сколько это стоило.

## 4. Зеркало прода на ноуте

```bash
bash scripts/sync-from-prod.sh          # база + файлы
bash scripts/sync-from-prod.sh --db     # только база, ~20 МБ
```

Односторонняя операция прод → ноут. Локальная база перед заменой бэкапится в
`.local-backups/`. Обратного направления нет и быть не должно.

Зачем: проверять генерацию, вёрстку и миграции на реальных данных, не трогая боевой сайт.
Сегодня это поймало две ошибки до деплоя.

⚠️ После синхронизации режим ИИ приезжает с прода (`openai`). Для бесплатной работы
переключить в Админ → 🤖 ИИ-провайдер.

## 5. Провайдер: платно или бесплатно

Админ → 🤖 ИИ-провайдер. Отдельно картинки и тексты. Режим хранится в базе и переживает
деплой. Уйти в «локально» нельзя, если служба не отвечает — иначе генерация тихо
перестала бы работать.

**На проде «локально» недоступно** — сервер не видит ноутбук. Бесплатный режим = локальный
стек на ноуте плюс скрипты, которые отдают результат на прод.

### Замер на M4/24 ГБ (28.07.2026)

| | результат |
|---|---|
| `llama3.1:8b` | 172 с на 4 слова, **брак** — битые символы |
| `qwen3:14b` | 28 мин на 4 слова, качество хорошее |
| `gpt-4o-mini` | секунды, $0.0002 за слово |

**Вывод: тексты — облаком, картинки — локально.** Локальная генерация текстов
непрактична: курс из 406 слов ≈ 40 часов против часа и $0.10.

Узкое место железа — не объём памяти, а её пропускная способность. Для Mac Studio смысл
в Ultra, а не просто в 128 ГБ.

⚠️ У Ollama окно контекста по умолчанию 4096 — этого мало, ответ обрывается на полуслове.
Клиент ходит в родной `/api/chat`, где `num_ctx` задаётся явно (16k). Через
OpenAI-совместимую прослойку это невозможно.

## 6. Правила, выведенные из найденных багов

**Язык передавать явно.** Два бага из девяти были от того, что язык не доехал:
фильтр служебных слов проверял английские слова по немецкому списку; примеры в промпте
генерации были немецкими для всех языков. Любая языкозависимая функция обязана принимать
`targetLang`.

**Пример в промпте сильнее инструкции.** Написать «пиши по-испански» и оставить рядом
пять немецких примеров — значит получить немецкий. Меняете язык — меняйте примеры.

**Проверять данные, а не доверять модели.** 600 масок и 70 пропусков были сломаны
месяцами, потому что валидации не было ни в одном пути генерации. Всё, что модель
кладёт в базу, должно проходить проверку — и лучше чиниться детерминированно, без ИИ.

**Данные важнее кода.** Починка генератора не переписывает то, что уже сгенерировано.
После правки логики почти всегда нужен отдельный проход по базе.
