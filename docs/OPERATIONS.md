## 1. Аудит материала — запускать после каждой загрузки уроков

```bash
node scripts/audit-exercises.mjs            # всё
node scripts/audit-exercises.mjs --lang de  # один язык
```

Ничего не меняет и не тратит: читает прод и печатает отчёт. Делит находки на два уровня:

- **🔴 блокер** — упражнение нельзя пройти в принципе;
- **🟡 важно** — пройти можно, но учит неверно.

Что проверяет: невыполнимые маски «Добавь букву»; пропуск в «Заполни пропуск» и наличие
верного ответа среди вариантов; повторы вариантов; битый индекс правильного ответа;
неполные спряжения; пустые слова в диктанте; **язык контента против языка курса**;
род существительного по суффиксу; заглавную букву.

### Урок, который стоил дороже всего

Первая версия аудита нашла «155 проблем» — и половина оказалась ложной. Правила
`-ier→der`, `-chen→das`, `-ion→die` обвиняли **правильные** слова: `das Papier`,
`der Kuchen` (пирог, не уменьшительное), `der Skorpion`. Проверка заглавной ругалась
на `der beste Freund`, где строчное слово — прилагательное.

**Правило с исключениями хуже, чем его отсутствие:** оно заставляет «чинить» исправное.
В аудите остались только суффиксы без исключений. Если добавляете правило — сначала
прогоните на всей базе и посмотрите, что оно ловит.

## 2. Картинки — рисуются на ноутбуке, бесплатно

```bash
caffeinate -i node scripts/draw-images-worker.mjs --mode missing --lang de --limit 999
```

Режимы: `missing` (нет картинки), `photos` (заменить фото на рисунок),
`align` (раздать готовую картинку дублям, без рисования), `--ids 1,2,3` (точечно).

**Почему ноут ходит на сервер, а не наоборот.** Сервер физически не видит ноутбук.
Чтобы видел, ноут пришлось бы выставить в интернет через туннель — тогда домашний
интернет становится частью продакшена, а закрытая крышка ломает генерацию на сайте.
Здесь наоборот: ноут сам забирает работу. Наружу ничего не открыто; ноут уснул —
следующий запуск продолжит с того же места.

Практика: ~2 минуты на картинку (M4), `caffeinate -i` держит машину бодрой, пока идёт
работа. **С закрытой крышкой Mac всё равно уснёт** — оставляйте экран открытым.
Draw Things должен быть запущен.

Цена вопроса: 106 картинок за ночь стоили **$0.00**. Через `gpt-image-1` вышло бы ≈$4.30,
а на всю базу — больше сотни долларов. Ради этого всё и делалось.

## 3. Журнал операций — Админ → 📜 Журнал

Утренняя проверка ночного прогона. Смотреть три цифры:

| показатель | норма |
|---|---|
| **Потрачено** | **$0.000** в бесплатном режиме. Ненулевое = что-то ушло на платный ключ |
| **Ошибок** | 0. Растёт ночью — Draw Things закрылся или ноут уснул |
| **Среднее время** | ~2 мин на картинку. Стало 5 — машина перегружена |

Пишутся: разбор фото (самый дорогой шаг), генерация упражнений, переводы на локали,
расшифровка аудио, каждая картинка. У каждой строки видно **чем считали** —
`local` (бесплатно) или `openai` (деньги) — и сколько это стоило.

## 4. Зеркало прода на ноуте

```bash
bash scripts/sync-from-prod.sh          # база + файлы
bash scripts/sync-from-prod.sh --db     # только база, ~20 МБ
```

Односторонняя операция прод → ноут. Локальная база перед заменой бэкапится в
`.local-backups/`. Обратного направления нет и быть не должно.

Зачем: проверять генерацию, вёрстку и миграции на реальных данных, не трогая боевой сайт.
Сегодня это поймало две ошибки до деплоя.

⚠️ После синхронизации режим ИИ приезжает с прода (`openai`). Для бесплатной работы
переключить в Админ → 🤖 ИИ-провайдер.

## 4а. Наборы — второй способ учить те же слова

Урок — это страница учебника. Набор — та же лексика, собранная по смыслу: «Еда», «Семья»,
«Глаголы», «Грамматика». Слово сознательно живёт и в уроке, и в наборе — это не дубль,
который мы вычищали. Дубль — это когда слово встречается дважды **внутри** уроков курса
или дважды **внутри** наборов; и то, и другое почищено 28.07.2026.

Разложить весь курс по наборам (запускать **на сервере**, нужен ключ OpenAI):

```bash
docker compose -f docker-compose.prod.yml exec -T backend node scripts/build-sets.mjs --lang en
docker compose -f docker-compose.prod.yml exec -T backend node scripts/build-sets.mjs --lang en --apply
docker compose -f docker-compose.prod.yml exec -T backend node scripts/finish-sets.mjs
```

Без `--apply` печатается смета и не тратится ничего. Классификация по темам идёт на **gpt-4o**
(нужно знание рода и смысла слова), упражнения и переводы — на gpt-4o-mini. Картинки не
генерируются: платная генерация выключена в супер-админке, берутся только готовые из банка.
Порядок en: 589 слов → 23 темы → $0.23.

**Почему два скрипта, а не один.** `distributeWordsToSets` возвращает ответ сразу, а обогащение
(упражнения, переводы на локали) запускает фоном — так задумано для кнопки «В наборы» в уроке:
учитель не ждёт. Но у этого фона нет владельца: когда процесс, который его начал, завершается,
недоделанная работа умирает вместе с ним. У бэкенда это незаметно — он работает дальше. У разового
скрипта заметно сразу: 482 английских слова из 589 остались без упражнений. `finish-sets.mjs`
доводит такие наборы до конца, идемпотентен, запускать можно сколько угодно раз.

**Скрипты обслуживания живут в `backend/scripts/`** и попадают в образ (`COPY scripts/` в
Dockerfile). До 28.07.2026 копировался только `src/`, и любой запуск через
`docker compose exec backend node scripts/...` падал с MODULE_NOT_FOUND — при том, что заголовки
самих скриптов именно так и предписывали их запускать.

## 5. Провайдер: платно или бесплатно

Админ → 🤖 ИИ-провайдер. Отдельно картинки и тексты. Режим хранится в базе и переживает
деплой. Уйти в «локально» нельзя, если служба не отвечает — иначе генерация тихо
перестала бы работать.

**На проде «локально» недоступно** — сервер не видит ноутбук. Бесплатный режим = локальный
стек на ноуте плюс скрипты, которые отдают результат на прод.

### Замер на M4/24 ГБ (28.07.2026)

| | результат |
|---|---|
| `llama3.1:8b` | 172 с на 4 слова, **брак** — битые символы |
| `qwen3:14b` | 28 мин на 4 слова, качество хорошее |
| `gpt-4o-mini` | секунды, $0.0002 за слово |

**Вывод: тексты — облаком, картинки — локально.** Локальная генерация текстов
непрактична: курс из 406 слов ≈ 40 часов против часа и $0.10.

Узкое место железа — не объём памяти, а её пропускная способность. Для Mac Studio смысл
в Ultra, а не просто в 128 ГБ.

⚠️ У Ollama окно контекста по умолчанию 4096 — этого мало, ответ обрывается на полуслове.
Клиент ходит в родной `/api/chat`, где `num_ctx` задаётся явно (16k). Через
OpenAI-совместимую прослойку это невозможно.

## 6. Правила, выведенные из найденных багов

**Язык передавать явно.** Два бага из девяти были от того, что язык не доехал:
фильтр служебных слов проверял английские слова по немецкому списку; примеры в промпте
генерации были немецкими для всех языков. Любая языкозависимая функция обязана принимать
`targetLang`.

**Пример в промпте сильнее инструкции.** Написать «пиши по-испански» и оставить рядом
пять немецких примеров — значит получить немецкий. Меняете язык — меняйте примеры.

**Проверять данные, а не доверять модели.** 600 масок и 70 пропусков были сломаны
месяцами, потому что валидации не было ни в одном пути генерации. Всё, что модель
кладёт в базу, должно проходить проверку — и лучше чиниться детерминированно, без ИИ.

**Данные важнее кода.** Починка генератора не переписывает то, что уже сгенерировано.
После правки логики почти всегда нужен отдельный проход по базе.

**Перед деплоем проверять импорты запуском, а не `node --check`.** 12.08.2026 бэкенд
две минуты лежал в рестарт-цикле: функцию переименовали, импорт в другом файле остался
старый. `node --check` этого не видит — он проверяет синтаксис одного файла, а не связывание
ESM-модулей; юнит-тесты роутеры не импортируют. Дешёвая страховка перед каждым деплоем:

```bash
cd backend && node -e "import('./src/index.js').then(()=>{console.log('ИМПОРТЫ ОК');process.exit(0)}).catch(e=>{console.error(e.message);process.exit(1)})"
```

**Отчёты, за которые заплачено, забирать из контейнера сразу.** 13.08.2026 отчёт
второго эшелона (539 проверенных находок, $0.023) и исходный отчёт аудита ($0.10)
исчезли: они лежали в `/tmp` контейнера, а бэкенд пересобирали. Пересборка образа
= новый `/tmp`. Всё, что стоило денег, вытаскивать на ноут той же командой, что и
породила:

```bash
ssh seoshkin-tools-core "docker cp \$(docker ps -qf name=translate-backend):/tmp/отчёт.json /tmp/"
scp seoshkin-tools-core:/tmp/отчёт.json docs/audits/
```

**Скрипт правки данных обязан сначала печатать план.** Того же 13.08 проверка
согласования собиралась заменить `kann`→`kane` и `bin`→`bie`: инфинитив определялся
по хвосту «-n», под который попадают личные формы. Ошибку увидели в плане, до записи
в базу. Двухшаговость (план → `--apply`) стоит одной лишней команды и спасает материал.

**Вердикт дешёвой модели — не приговор, а заявка.** Второй эшелон подтвердил 539 находок
из 794, но ручная вычитка 16 штук показала: реальных примерно 40%. `Das Glas ist voll`
и `Du fängst das Spiel an` — нормальные фразы, забракованные зря. Чинить материал по
списку претензий нельзя; чинить нужно то, что подтверждено глазами или что чинится
детерминированно.


**Два состояния там, где их три.** 05.09.2026 плашка узла на «Пути» не закрывалась:
`null` означал одновременно «человек закрыл» и «ещё ничего не выбирали», а во втором
случае плашка показывается у текущего урока — она закрывалась и тут же открывалась
снова. У остальных узлов работало, у первого нет. Если у состояния есть значение
«по умолчанию показываем вот это», оно обязано отличаться от «пользователь закрыл»:
`undefined` — не трогали, ключ — выбрано, `null` — закрыто.

**Правило «открыт ли элемент» — одно на весь компонент.** Там же оно было переписано
в трёх местах (отрисовка, обработчик тапа, раскладка) и разошлось: тап считал текущий
урок закрытым и «открывал» уже открытое. Такие предикаты выносить в одну функцию —
разошедшиеся копии дают баг, который не виден в коде ни одного из мест.

**Всплывающую панель класть ПОД элемент, а не сбоку.** Плашка вставала слева или справа
по половине экрана, и у правых узлов половина уезжала за край: рядом с кнопкой на телефоне
места нет, снизу есть всегда. Позицию считать в координатах контейнера и прижимать
`clamp`-ом внутрь него. И сразу раздвигать то, что ниже, на высоту панели — иначе она
накрывает следующий элемент и до него не дотянуться, не закрыв текущий.

**Скролл к полю по событию вьюпорта — самоподдерживающийся цикл.** Экран в диктанте
прыгал с первого набранного символа: Android достраивает строку подсказок, высота
клавиатуры меняется, `resize` дёргает плавный `scrollIntoView`, тот сам меняет вьюпорт —
и так по кругу. Скроллить только в момент ПОЯВЛЕНИЯ клавиатуры (переход закрыта→открыта),
а не на каждое её шевеление.

**Новое окно на главной — проверить, что оно не столкнулось с туром.** Тур стартует сам
при первом входе, и окно «С чего начать» всплыло поверх него разом. Любая модалка на `/`
должна уметь сказать туру «подожди» (`store/intro.js`, как `useCourseGateStore`).

**`npm test` в backend стирает базу из `DATABASE_URL`.** `test/helpers.js` делает
`TRUNCATE ... users ... CASCADE`, а локальный `.env` смотрит на зеркало прода. Гонять
только на одноразовом Postgres. Миграции с нуля на нём не проходят: `042_schools.sql`
вставляет школу с `owner_id = 1`, поэтому перед вторым прогоном нужен затравочный
пользователь.

```bash
docker run -d --rm --name dl_test_pg -e POSTGRES_USER=t -e POSTGRES_PASSWORD=t \
  -e POSTGRES_DB=t -p 5499:5432 postgres:16-alpine
export DBT="postgresql://t:t@localhost:5499/t"
DATABASE_URL=$DBT JWT_SECRET=test npm run migrate            # упадёт на 042
docker exec dl_test_pg psql -U t -d t -c \
  "INSERT INTO users (email, password_hash, role) VALUES ('seed@example.com','x','owner');"
DATABASE_URL=$DBT JWT_SECRET=test npm run migrate            # добьёт
DATABASE_URL=$DBT JWT_SECRET=test npx vitest run             # ждём 358/360
docker rm -f dl_test_pg
```

Два теста падают штатно и это не регрессия: `auth.test.js` (вайтлист owner берётся из
окружения) и `processor.test.js` (нужен ключ OpenAI).

**После выкатки браузер держит старые файлы.** Приложение — PWA. 05.09.2026 на этом
потеряли круг: правка уехала на бой, а проверка шла по старому бандлу, и починенный баг
«воспроизвёлся». Проверять только после перезагрузки страницы (в APK — убить приложение
из списка задач), а сомнения снимать сверкой имени бандла:

```bash
curl -s https://deutschlernen.ai/ | grep -oE '/assets/index-[A-Za-z0-9_-]+\.js'
```

**Размер бандла роняет сборку молча.** Главный чанк перевалил за 2 МиБ, и
`vite-plugin-pwa` отказался класть его в офлайн-кеш — `npm run build` упал уже ПОСЛЕ
успешной сборки, на генерации service worker. Потолок поднят до 6 МиБ
(`frontend/vite.config.js`), но это отсрочка: лечится code-splitting по маршрутам.
