# 🗣 Наборы фраз — дизайн

Дата: 2026-08-12 · Автор: Opus (с Павлом) · Статус: согласован на брейншторме, ждёт вычитки Павла

## Контекст

Павел прислал рекламную картинку (`docs/nabory_fraz/`): тема **KOCHEN**, уровень **A1**,
картинка, 11 пронумерованных фраз с эмодзи, кнопки **HÖREN** и **LESEN**, озвучка.

Запрос Павла своими словами: «учение слов хорошо, а вот произношение и сборка предложения —
это другое», «мне нужно учить фразы, чтобы понимать учителя». То есть дыра в системе:
слова закрыты семью типами упражнений, а **целые фразы — ничем**.

Второй запрос: 2790 предложений из тетради разложить по темам в разговорник. При этом
**в уроки фразы генерируем сами** — тетрадные могут содержать ошибки учителя и распознавания.

Уровень Павла сейчас — **A0/A1**, под него и делаем. B1/B2 (включая описание картинки
для зачёта) — отдельным спринтом, в эту спеку не входит.

## Решения брейншторма

| Вопрос | Решение |
|---|---|
| Формат | Экран-список как на картинке **+** режим тренировки на тех же фразах |
| Привязка | Тема — самостоятельная сущность, урок на неё ссылается (один набор — много уроков) |
| Источник | Тетрадь даёт **темы**, сами фразы ИИ пишет заново с валидацией |
| Тренировка фразы | 3 шага: 🎧 слушаю → 🧩 собираю → 🎤 говорю |
| Откуда наборы | Каталог тем + автоматом к уроку + личный набор ученика |
| Старый `phrasebook` | Переносим в новую модель (станет мультилокальным и тренируемым) |
| Место в UI | **Штатный тип упражнения в каждом уроке**, в ряду с «выбери ответ» и флеш-картами |

## Цель

Ученик открывает любой урок и видит среди упражнений карточку **«🗣 Фразы урока»**.
Внутри — 8–12 живых фраз из слов этого урока: их можно прослушать подряд (как подкаст,
не глядя в экран) и отработать по три шага каждую. Отдельный раздел «Фразы» показывает
те же фразы, сгруппированные по темам — это и есть разговорник.

## Модель данных (миграция 062)

Существующие таблицы **не трогаем**: `phrase_sets` (011) занята сохранёнными текстами из
`TextReader`, `phrasebook` (019) хардкодит `de`/`ru` и мультилокальной быть не может.

```sql
-- Тема-набор: KOCHEN / A1 / картинка
CREATE TABLE phrase_topics (
  id          SERIAL PRIMARY KEY,
  slug        VARCHAR(80)  NOT NULL,
  lang        VARCHAR(5)   NOT NULL,               -- целевой язык: de | en | es
  level       VARCHAR(4)   NOT NULL DEFAULT 'A1',  -- A0 | A1 | A2 | B1 | B2
  title       VARCHAR(120) NOT NULL,               -- на целевом языке: «Kochen»
  title_i18n  JSONB        NOT NULL DEFAULT '{}',  -- переводы названия на 10 локалей
  emoji       VARCHAR(8),
  image_url   TEXT,
  source      VARCHAR(12)  NOT NULL,               -- catalog | lesson | teacher | student
  owner_id    INTEGER REFERENCES users(id)   ON DELETE CASCADE,   -- NULL = общий каталог
  school_id   INTEGER REFERENCES schools(id) ON DELETE CASCADE,
  lesson_id   INTEGER REFERENCES lessons(id) ON DELETE CASCADE,   -- если сделан к уроку
  published   BOOLEAN      NOT NULL DEFAULT FALSE, -- черновик до вычитки человеком
  created_at  TIMESTAMPTZ  DEFAULT now(),
  UNIQUE (slug, lang, level, COALESCE(owner_id, 0))
);

-- Фраза набора
CREATE TABLE phrases (
  id           SERIAL PRIMARY KEY,
  topic_id     INTEGER NOT NULL REFERENCES phrase_topics(id) ON DELETE CASCADE,
  position     INTEGER NOT NULL,
  text         TEXT    NOT NULL,                   -- «Ich wasche meine Hände.»
  translations JSONB   NOT NULL DEFAULT '{}',      -- {ru:…, en:…, uk:…} — 10 локалей
  emoji        VARCHAR(8),
  word_ids     INTEGER[] NOT NULL DEFAULT '{}',    -- слова урока, задействованные во фразе
  created_at   TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_phrases_topic ON phrases(topic_id);

-- Прогресс ученика по фразе (SM-2, как у упражнений)
CREATE TABLE user_phrase_progress (
  user_id          INTEGER NOT NULL REFERENCES users(id)    ON DELETE CASCADE,
  phrase_id        INTEGER NOT NULL REFERENCES phrases(id)  ON DELETE CASCADE,
  step_listen      BOOLEAN NOT NULL DEFAULT FALSE,
  step_build       BOOLEAN NOT NULL DEFAULT FALSE,
  step_speak       BOOLEAN NOT NULL DEFAULT FALSE,
  easiness_factor  NUMERIC(4,2) DEFAULT 2.5,
  interval_days    INTEGER      DEFAULT 0,
  repetitions      INTEGER      DEFAULT 0,
  next_review_date DATE         DEFAULT CURRENT_DATE,
  updated_at       TIMESTAMPTZ  DEFAULT now(),
  PRIMARY KEY (user_id, phrase_id)
);
```

Следствия:
- один набор переиспользуется в любом числе уроков и школ — генерим и платим один раз;
- личный набор ученика — та же таблица с `owner_id`, отдельного кода не нужно;
- картинка темы идёт через существующий воркер картинок (локально, $0).

### Перенос старого разговорника

Идемпотентный скрипт `backend/scripts/migrate-phrasebook.mjs`: записи каждого пользователя
группируются по `category` → личные `phrase_topics` (`source='student'`, `owner_id=user_id`),
строки → `phrases` с `translations = {ru: <ru>}`, остальные локали добираются позже пакетно.
Старая таблица **остаётся нетронутой** как бэкап; страница `Phrasebook.jsx` переключается
на новую модель. Повторный запуск ничего не дублирует (ключ — `owner_id + slug`).

## Место в уроке — и почему не в CORE_EXERCISE_TYPES

В `claude.js:604` пять `CORE_EXERCISE_TYPES`, и вся арифметика покрытия и зачёта строится
как «каждое слово × каждый тип» (урок 12: зачёт 50 = 7 слов × 7 типов + сирота).

Набор фраз в эту формулу не ложится: он **один на урок** и покрывает сразу десяток слов.
Поэтому:

- в `CORE_EXERCISE_TYPES` фразы **не добавляем** — иначе поедут счётчики и размер зачёта;
- в ряду типов урока (`ExerciseSession.jsx:366`, `TYPE_LABELS`) фразы — **отдельная карточка**
  «🗣 Фразы урока» со своим прогрессом «7 из 11»;
- в общем счёте упражнений урока набор считается **одной единицей**, а не одиннадцатью.

Тест на регрессию обязателен: размер зачётной сессии до и после внедрения должен совпасть.

## Экраны

### Экран набора (как на картинке)

Заголовок темы на целевом языке, чип уровня, картинка, нумерованный список фраз с эмодзи.
Тап по фразе — озвучка (браузерный TTS, бесплатно). Внизу:

- **🎧 HÖREN** — проигрывает набор подряд, с паузами; слушать можно не глядя в экран;
- **📖 LESEN** — показать/скрыть перевод. **По умолчанию скрыт**: если русский виден сразу,
  глаз читает его и немецкий не запоминается;
- **«Тренировать»** — основная кнопка.

### Экран тренировки — три шага на фразу

1. **🎧 Слушаю** — звук без текста, выбор из 3 вариантов перевода. Не понял — повтор,
   второй раз медленнее. Это тренировка «понять учителя на слух».
2. **🧩 Собираю** — слова вперемешку, складываем фразу. Компонент `TapText.jsx` уже есть.
3. **🎤 Говорю** — микрофон, сравнение по немецкой фонетике. Логика `SpeechExercise.jsx` +
   `utils/speechMatch.js` + `germanPhonetic.js` уже есть.

Внизу — прогресс по набору, в конце — существующий экран с конфетти.

**Гибкость шага «говорю» (требование Павла):**
- кнопка «пропустить» есть всегда, фраза засчитывается по двум первым шагам;
- Web Speech API отсутствует в Safari/iOS (включая PWA) и требует сети в Chrome — там шаг
  скрывается автоматически, вместо него «прослушал и повторил» с самопроверкой;
- порог совпадения мягкий, как сейчас в `SpeechExercise`: это тренажёр, не экзамен;
- **ИИ-оценка произношения в MVP не делается** — сейчас проверка браузерная и бесплатная.
  Точка расширения на будущее: audio-модель слышит акцент, но стоит денег за секунду звука —
  включаем только отдельным решением Павла с оценкой стоимости.

### Повторение (SRS)

Фраза — единица повторения, как слово. Пройденная уходит в интервал SM-2 и всплывает
в общей сессии. **На повторе даётся только шаг «слушаю»** — смысл повтора в том, чтобы
узнать фразу на слух в потоке речи, а не собирать заново уже собранное.

## Генерация контента

### Шаг 1. Темы из тетради — $0.05

2790 пригодных `lesson_sentences` прогоняются через `gpt-4o-mini`: не переводим и не
переписываем, только спрашиваем тему каждого. Получаем карту того, что реально даёт
учитель, с частотами. Отчёт в `docs/audits/`, список тем **утверждает Павел**, не модель.

### Шаг 2. Фразы пишет ИИ заново — ~$0.90 на 94 урока

Один вызов **`gpt-4o`** на урок (не mini: фразы увидит вся школа, пишутся один раз,
экономия здесь выйдет боком — как на аудите 07.08).

Промпт для A0/A1 — жёсткие рамки, потому что слово «A1» модель понимает вольно и выдаёт
`Nachdem ich gekocht hatte…`. По выводу из `OPERATIONS.md` — **пример в промпте сильнее
инструкции**, поэтому в промпт кладутся эталоны:

```
Ich gehe in die Küche.
Ich wasche meine Hände.
Ich koche Suppe im Topf.
```

Рамки: настоящее время; 4–7 слов; одна грамматическая конструкция на фразу; без придаточных;
каждая фраза использует 1–3 слова этого урока; к каждой — эмодзи.

Урок из 3–4 слов → набор из 5–6 фраз, а не из 11: лучше меньше, чем вода ради числа.

### Шаг 3. Проверка — бесплатно, и человек последний

Каждая фраза проходит гейт предложений (миграция 061) и `wordGate` — оба офлайн.
Не прошла — не публикуется. Плюс правило Павла после инцидента с триажем: **вердикты
модели не применяются автоматически**. Набор создаётся как `published=false`, в админке
Павел листает фразы и жмёт «опубликовать».

### Шаг 4. Переводы на 10 локалей — ~$0.25

`gpt-4o-mini` батчами, механикой `translateWordsToAllLangs`.

### Шаг 5. Картинки тем — $0

Существующий воркер картинок на ноуте, ~106 c на картинку.

### Итого

| Что | Цена |
|---|---|
| Разбор тем из тетради | $0.05 |
| Генерация фраз к 94 урокам (`gpt-4o`) | $0.90 |
| Переводы ~1000 фраз на 10 локалей | $0.25 |
| Картинки | $0 |
| **Разово** | **≈ $1.20** |
| Каждый новый урок дальше | ≈ $0.01 |

**Ни цента не тратится, пока Павел не скажет «запускай».** Скрипт без `--apply` печатает
только план — как `fix-audited-exercises.mjs`.

## Пути появления наборов

1. **Новый урок** — шаг в конвейере создания, сразу после генерации упражнений, рядом
   с картинками.
2. **94 существующих урока** — разовый идемпотентный `backend/scripts/backfill-lesson-phrases.mjs`
   (без `--apply` — план; повторный запуск не платит второй раз за сделанное).
3. **Учитель** — кнопка «создать набор»: тема + уровень → черновик → правка руками → публикация.
4. **Ученик** — складывает фразы в личный набор (перенесённый разговорник).

## Деградация и ошибки

- Нет кредитов / модель молчит → урок создаётся **без** набора и помечается флагом;
  в админке список «уроки без фраз», добиваются одной командой. Урок не ломается.
- Фраза не прошла гейт → не публикуется, пишется в журнал операций (`kind=phrase_gate`).
- Офлайн: фразы и переводы кладутся в существующий офлайн-кеш; TTS работает без сети,
  шаг «говорю» скрывается.

## Тесты

- валидатор уровня A0/A1: длина, отсутствие придаточных и прошедшего времени;
- сборка набора из слов урока (в т.ч. урок из 3 слов → 5–6 фраз);
- идемпотентность обоих скриптов (бэкфилл и перенос разговорника);
- **регрессия зачёта**: размер зачётной сессии до и после внедрения совпадает;
- прогресс набора не течёт в математику покрытия слов.

## Что НЕ входит (отдельными задачами в IDEAS.md)

- **Тумблер ролей учитель/ученик** для Павла. Причина проблемы найдена: `courses.js:86`
  и `CourseView.jsx:237` исключают `role === 'owner'` из дрипа — поэтому у Павла нет
  календаря занятий. Тумблер обязан переключать **только режим отображения и дрип**,
  не реальные права на бэкенде, иначе это дыра в доступе к чужим данным.
- **Bildbeschreibung B1/B2** — описание картинки по условиям с оценкой по критериям зачёта.
- **Редизайн интерфейса ученика** — «4 кнопки как в Duolingo», ждём макет Павла.
  Тогда же «Фразы» встают в новую навигацию, а не сбоку.
- **Наборы B1/B2** — уровень в модели поддержан, но контент со своим промптом и критериями.
